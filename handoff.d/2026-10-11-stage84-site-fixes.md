## Stage84 follow-up — site fixes: electorate polls, minor-party names and an Other row, 2026-10-11

- The site's seat-poll evidence (`scripts/site_evidence/build.py`) now reads the electorate-poll run that `seatPolls.electorateRun` pins, the run the forecast reads, instead of the Stage66/Stage70 files. The old list held 6 of the run's 12 polls and marked every general-seat poll unused, so the Polls page showed only the 3 Māori polls. Use flags now come from the forecast's own readers (`scripts.seat_polls.live.combine`; the latest Māori poll per seat by the data cutoff), and poll shares are named by the seat's official candidate on that party's line.
- Polls page: every electorate poll is listed; ones the forecast did not use are greyed and marked "Not used". Seat pages: minor-party and independent candidates with under 1% chance and under 5% median share fold under one collapsed "Other" row (two or more); minor-party names show as short names (NZ Loyal, Legalise Cannabis, Conservative, Alliance, Outdoors & Freedom, Animal Justice, Vision NZ, Free Palestine, Te Tai Tokerau Party), never a ballot-group key.
- Not touched: the model, the config, any forecast number, the draw bank, `data/sources.json`. The saved `data/processed/site-evidence/2026-10-07/evidence.json` is regenerated. The live forecast embeds the old evidence, so the fix reaches the live site only through a correction release of the 2026-10-07 forecast (Publish run with the publish box ticked and `supersedes` set to the live release id), not a site-only republish.
