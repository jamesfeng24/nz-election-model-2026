# NZ Election Forecast

The built website and the published forecasts behind NZ Election Forecast, a forecast of what would happen if the 2026 New Zealand general election were held today: https://jamesfeng24.github.io/

These files are generated automatically from the research repository (https://github.com/jamesfeng24/nz-election-model-2026) after each weekly poll update, and are replaced on every update, so please do not edit them by hand.

- `forecasts/` holds every published forecast. `forecasts/index.json` lists them and each one is a complete `snapshot.json`.
- Everything else is the website.
