# Stage33 same-equation numerical evaluation

Before any held-out scoring, the initial inherited double-precision profile evaluation produced22 numerical abstentions among56 unique jobs. They are preserved in `initial-numerical-attempt.json`, with original evaluator/code hashes and fit parameters. A traced primary2014 S line search returned `ABNORMAL` at theta1.83765024, loss1.1255006793886713 and analytic gradient1.5124e-9. Finite differences at1e-5/1e-6 agreed, whereas smaller steps exposed rounded loss cancellation. Its small gradient did **not** override the frozen success requirement.

The Stage33 explicit S/R interface evaluates the **same** cross entropy with direct reductions instead of platform BLAS products. A preserved intermediate attempt used longdouble; this Apple runtime exposes it at float64 precision, so32 jobs still abstained. Its exact intermediate code hash was not captured before editing and remains explicitly unavailable in the audit; the recorded-with code hash is not presented as its generator. For fixed kappa, the inner optimizer evaluates `L(theta,kappa) - L(0,kappa)` using its algebraic log-ratio expression. This theta-constant shift preserves the optimizer, objective minimizer and gradient; absolute cross entropy is returned to the outer floor searches. It avoids subtracting large rounded terms near an optimum. If a double-precision fixed-start run reports unsuccessful status, repeat **that same start**, optimizer, bounds and tolerances once using the same shifted objective/analytic gradient evaluated at Decimal50 precision. Only a successful retry passing the unchanged projected-gradient and all-start/independent checks can be accepted; otherwise abstain. Count every precision retry. This deterministic numerical fallback uses no holdout information or different starting values. No source data, parameter bounds, starts, ftol/gtol, projected-gradient, objective-agreement, rank or stopping rule changes. Original Stage22 machinery and historical outputs remain untouched.

This is a pre-scoring numerical implementation correction, not tuning to a holdout or a new statistical formulation. The original failed attempts remain visible.
