## Fixed inputs and permitted joins

Use the immutable Stage 14 **213-contest** transition frame for validated source/target electorate IDs and geography; Stage 18's pre-fit election-local candidature/party mapping inventory for the full target slate and its existing abstentions; six processed election records for **source** candidate/party vote shares and target party-group membership only; the six preserved Stage 11 local split matrices for source party-row mass, percentage and destination IDs; and Stage 5's eligible exact historical party continuity. Use Stage 11's source snapshot and Stage 18's source snapshot to verify required registry records and raw checksums. Add a Stage 20 stage-specific hash manifest of all actually read processed contracts. Unrelated registry additions remain allowed.

The join key is `(sourceYear,targetYear,sourceElectorateId,targetElectorateId,targetPartyKey)` from the fixed frame and exact Stage 18 target mapping, then a **unique eligible** target-to-source party continuity record, a unique source local party ballot row and at most one source candidate destination with that source party key. Source and target candidate IDs are election-local; names, person links, winner flags and target candidate totals are never join keys. Reject duplicate IDs, row/matrix inconsistencies and an unsupported boundary regime. Source candidate votes and source party votes are earlier-election evidence; their denominators remain distinct. The published source split percentage is rounded conditional on the **source party-ballot row**, not a candidate-share count.

## Predeclared classification before counts

The whole target contest retains Stage 18's held-general and unambiguous full-slate/party-vector gate. Missing or internally inconsistent source matrix, duplicate party row, missing row for an **eligible continuing party**, or ambiguous continuity/category mapping makes the whole contest abstain. A target candidate with affirmative no-party-group status has a neutral baseline intensity and no S/V feature. An exact party category with no eligible source continuity (entry/exit) or with no source candidate destination is a visible candidate-level neutral fallback, not an inferred zero feature or a person-level newcomer. A present source row with zero party-ballot mass leaves S undefined; V may remain available from independently published source candidate/party totals. A printed `0.00` cell on a **positive** row is observed rounded evidence, not missingness. The four future model restrictions share the same contest IDs; feature absence never silently removes only the harder candidates from one ablation.

Stage 20 calculates only input availability, source rounding feasible intervals and within-slate predictor contrasts. It does **not** read target candidate votes, target winner flags, person confidence or Stage 18 fitted κ/predictions. An in-memory counterfactual will change those forbidden fields while holding source facts fixed; feature IDs, classifications, training/evaluation samples and rank diagnostics must remain identical. Later observed target outcomes can be attached only in a separately authorized evaluation stage.

## Deliverables and stop rule

Generate a deterministic contest/candidate feature ledger, source dependency snapshot and manifest; report all 213 contests, all held-general candidate occurrences, source/target category support, by-fold training/evaluation coverage, fallbacks and abstentions. Compute rank using **within-slate** centered feature and floor-derivative columns on permitted inputs, with no target outcomes. Compare 2017 and 2023 against Stage 19's fixed minimum of 20 constructed contests and 20 contests with supported S per trained holdout. If either fails, freeze the limitation and stop before any future fitting; do not relax the threshold or substitute another viability feature. If gates pass, freeze a four-restriction fit-ready contract only. No coefficient, historical prediction, score, source acquisition, identity adjudication, Family A model or operational selection is authorized here.
