## Locked arithmetic and sample rules

For a point prediction and actual share, signed error is **prediction − actual** in percentage points. For model and control evaluated on the *same observation ID*, `Δabsolute = |error_model| − |error_control|` (pp) and `Δsquared = error_model² − error_control²` (pp²); **negative improves**. Derive each from saved predictions and evaluation-only actuals. Require exactly equal ID sets, years, units, denominator and information set before comparison; duplicates or missing actuals fail. Report paired mean and median, count improved/worse/tied, mean model/control MAE and RMSE calculated on the same set, plus the five largest absolute paired changes by ID within each fold. Influence is descriptive, not an exclusion rule. Preserve all candidate rows within a contest; Stage18 also reports contest-equal means and candidate-equal sensitivity separately. For Stage16/6, the party-seat is the unit and National/Labour never pool into a candidate-share composition.

Primary complete-share diagnostic: Stage18 fitted floor minus restricted zero-floor on 43/31/19 common contests (2011/2017/2023). Fitted minus uniform on all 63/64/44 constructed contests is contextual, because it confounds the floor with observed local party support. Stage16 primary response diagnostic: source-victory minus independently fitted common-intercept within each party/holdout on observed local party input; a nuisance-matched fixed-beta1 comparison is secondary. Stage6 fitted zero-intercept response minus one-for-one on the same party-seat/holdout is contextual. ## Interpretation and stopping

Classify a failure as predictive error, evidence/selection limit, output-coverage limit, missing forecast-time inputs or incompatible target/denominator. More than one can apply. Three already inspected transitions are development evidence, with shared election-level shocks and repeated seats; no candidate-iid significance or untouched validation claim. A source candidate-party gap is not an identified personal effect. A null operational selection is not a measured zero real-world effect. Stop after frozen summaries, two or fewer justified future experiment families, and one concrete next authorization recommendation. Do not search many subsets, refit a model, acquire evidence or build a 2026 forecast in this checkpoint.
