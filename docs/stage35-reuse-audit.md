# Stage35 reuse audit — implementation inspected, not model validation

## Concrete decision

**Adapt the compositional state-space architecture and independently reimplement a small owned national module.** Adopt Nixinova's versioned bulk observations (Unlicense), supplement with the pinned current Wikipedia party table (CC BY-SA attribution) and named original releases. Do not vendor or run the upstream statistical/publication stack. GPL reference files remain verbatim research sources with their licenses; no GPL code is imported/executed by our independently written data pipeline. If future implementation copies/adapts GPL implementation code, preserve GPL notices and review distribution licensing before doing so.

| Layer | Decision | Implementation evidence and reason |
|---|---|---|
| ingestion | adapt concepts/reimplement small adapter | Arie `data/wikipedia.py` detects headers; currently converts `<x` to x/2 and drops publication evidence/links. Our interval observations retain censoring and unknowns. Nixinova's one inline YAML panel avoids layout-dependent historical scraping; its docs explain day00. |
| cutoff | reimplement | `prep/marshal.py:build_dataset`, the inspected pollsters configuration and backtest caller use field end plus typical delay, not verified releases. Our5/10-day scenarios remain inferred; original publication overrides. Full-series snapshot revisions are not proven historical versions. |
| national model | adapt architecture, simplify | Inspected `model/numpyro_model.py` has compositional state, result bridges with increment density, correlated innovations, house/cycle/industry offsets, learned design effects and multiple likelihoods. Our single model omits term-house, campaign, heavy-tail and fundamental variants; frozen fixed observation inflation and regularized common error avoid that parameter expansion. |
| inference | adopt NumPyro NUTS interface next stage | Inspected `model/fit.py` uses JAX/NumPyro MCMC. No inference packages installed or fits run. Next stage isolates/pins only numerical inference dependencies; no Polars/PyArrow/Quarto/site stack. |
| validation | adapt chronological concepts/reimplement | `eval/backtest.py:backtest_case` excludes target results from marshal but ensemble weights in `weights_without({target})` use other targets, including later elections for earlier cases. Leave-one-election-out stacking is not our chronological protocol. No weights, reported accuracy or live draws imported. |
| publication/electorates | defer entirely | Arie's electorate editorial assumptions and ABM's candidate/coalition adjustments are unrelated to our owned candidate contracts. No live forecast/MMP outputs are training truth. |

## Pinned actual implementations and lineage

- Arie `ef76cf6562e1d028b4fff46d063f4b93945299de`: metadata, tree, parser/date/marshal, statistical model/fit, backtest, dependencies, pollster/calendar configuration; GPL-3.0. [Requested repository](https://github.com/ariedotcodotnz/nz-poll-of-polls).
- Nixinova `781f9eec93982eceeeac7f0ddf9fde649853b5ca`: `data.yml`, docs/readme/license; Unlicense. Transcribed Wikipedia, not original survey microdata. [Bulk panel](https://github.com/Nixinova/NZPolls).
- Peter Ellis `7aa741e78f52f38b020f4c7bc75fe294669abe2b`: prep/prior and actual Stan state-space program; GPL-3.0. Prep hard-codes pollsters, fills missing parties0 and assumes n1000; fundamentals prior code uses historical swing regression. Do not adopt those shortcuts or fundamental prior. [Original implementation](https://github.com/ellisp/nz-election-forecast).
- NZ Herald2023 actual legacy Stan/prep is pinned inside Arie's `legacy-r` lineage; source comments attribute Ellis and removal of political-science prior. Stan models unconstrained share states, fixed standard errors/inflator and explicit Reid method effect. Result observations at completed elections can be useful anchors; unrestricted marginal shares need coherent replacement. Original Herald repository was not separately fetched; this is an audit of the preserved legacy copy, not proof of byte identity with every upstream revision.
- [ABM methodology](https://abmvanhelsdingen.github.io/methodology.html) describes weekly national state-space draws for an election this week. Its preserved public site tree contains generated pages/widgets, **no statistical source implementation**. Consequently national-model correctness, election-day propagation and convergence cannot be verified from that site. Its link leads to Ellis; its electorate candidate denominator/adjustments are not adopted. Public tree SHA is recorded in `abm-tree.json`; no numerical model commit can be pinned because none was exposed.

The implementation audit identifies patterns, not externally validated coefficients or an endorsement of performance claims. No statistical dependency was installed merely to inspect code. Raw bytes/checksums/retrieval dates and failed main/master/empty-page routes are in the44-resource ledger. Empty Scoop responses are unavailable evidence, never confirmed publications.
